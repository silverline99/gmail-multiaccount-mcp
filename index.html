Gmail multiaccount MCP

A personal automation tool that runs on its developer's own computer.

This is a small Model Context Protocol server used by one person for their own bookkeeping. It reads that person's own Gmail messages and prepares drafts of outgoing invoice e-mails, with the invoice PDF and delivery note attached from files on the same computer.

What it does

  • Reads the developer's own Gmail messages to pull data into their invoicing spreadsheet.
  • Creates draft e-mails with attachments, so the invoice does not have to be assembled by hand.
  • Writes rows into the developer's own Google Sheets and updates their own invoicing records.

What it does not do

  • It never sends e-mail. Every draft is reviewed and sent by hand in Gmail.
  • It does not delete or archive messages.
  • It is not a product, is not distributed, and has no users other than its developer.

Privacy

No data leaves the developer's computer except to the Google APIs the tool needs in order to work. Details are in the privacy notice.
