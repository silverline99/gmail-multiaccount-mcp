Privacy Notice

Gmail multiaccount MCP · last updated 8 October 2026

This is a personal, local automation tool (“Gmail multiaccount MCP”, project ralyo-mcp) built and used solely by its developer for personal productivity. It runs as a local Model Context Protocol server on the developer's own machine. It is not a public product, it is not distributed to other users, and it is not offered as a service.

What the app does with Google user data

The app accesses only Gmail data belonging to the developer's own Google accounts, which they explicitly authorized through Google's OAuth consent flow. Two accounts are used, each with the narrowest scope its task needs:

ScopeAccountWhat it is used for
gmail.readonly personal inbox reading the developer's own messages (search, read) to extract data for their own bookkeeping
gmail.compose invoicing inbox creating drafts of outgoing invoice e-mails, with PDF attachments read from the local disk

The app never sends e-mail. It does not call users.messages.send or users.drafts.send; drafts are always reviewed and sent by the developer by hand in the Gmail web interface. It does not delete, archive or label messages.

How data is handled

  • All processing happens locally on the developer's own machine.
  • No data read from Gmail is transmitted to, stored on, or shared with any third party, server or service other than the Google APIs required to operate (Gmail API).
  • No Gmail data is used for advertising, resold, or used to train any model.
  • OAuth tokens are cached only on the developer's own machine, in files readable solely by the developer's user account, and are never uploaded anywhere.
  • Files attached to drafts are read from a short list of explicitly allowed folders on the developer's own machine; nothing else on the disk is read.
  • Data is retained only for as long as the local files exist; there is no server-side storage, database or backup.

Revoking access

The developer may revoke this app's access at any time at myaccount.google.com/permissions. Deleting the local token files has the same effect for that machine.

Contact

The app is operated by a single private individual, its developer. The support e-mail address for the app is shown on Google's consent screen when the app asks for access, and at myaccount.google.com/permissions.
