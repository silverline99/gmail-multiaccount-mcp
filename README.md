# Gmail multiaccount MCP — public pages

Homepage and privacy notice for a personal, local MCP server that reads its developer's own
Gmail and prepares invoice e-mail drafts. Published only because Google's OAuth consent screen
requires a reachable home page and privacy policy URL.

- Home page: https://silverline99.github.io/gmail-multiaccount-mcp/
- Privacy notice: https://silverline99.github.io/gmail-multiaccount-mcp/privacy/

The tool itself never sends e-mail; drafts are reviewed and sent by hand.
